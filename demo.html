Oldweb UI

A zero-dependency CSS library that skins any site with authentic interface looks from 1980–2020. Set one attribute, optionally add .r-* classes — classless elements are styled automatically.

Live theme: web20 — change from the sidebar

Install

CDN (all themes):

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@chabdulwahab/oldweb-ui@1.0.0/dist/oldweb-all.css">
<html data-oldweb="web20">

Or npm: npm install @chabdulwahab/oldweb-ui then import "@chabdulwahab/oldweb-ui".
