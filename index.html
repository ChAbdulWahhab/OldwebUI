Oldweb UI

A zero-dependency CSS library that skins any site with authentic interface looks from 1980–2020. Set one attribute, optionally add .r-* classes — classless elements are styled automatically.

Live theme: web20 — change from the sidebar

Install

CDN (all themes):

<!-- Option 1: jsDelivr GitHub CDN -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/ChAbdulWahhab/OldwebUI@v1.0.1/dist/oldweb-all.css">

<!-- Option 2: GitHub Pages Direct CDN (Immediate fallback) -->
<link rel="stylesheet" href="https://chabdulwahhab.github.io/OldwebUI/dist/oldweb-all.css">

<html data-oldweb="web20">

Or install via npm: npm install @chabdulwahab/oldweb-ui · Download from Releases.
